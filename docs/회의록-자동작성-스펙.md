# 회의록 자동작성 (Craig + Whisper) — 스펙 v0.1

Discord 음성 회의를 Craig로 녹음 → 자동 텍스트화(STT) → LLM 회의록 요약 → 앱의
`자료 > 🎙 회의록 자동작성` 에 회의 세션별로 보관한다.

## 확정된 설계 결정
- **STT 엔진**: 로컬 `faster-whisper` (GPU 서버). 무료·무제한·한국어 우수.
- **Craig 연동**: 자동 가져오기 — 녹음 ID/키(또는 `rec` 링크) 입력 → 백엔드 다운로드.
- **화자 구분**: Craig 화자별 멀티트랙 활용 — 트랙 파일명 = 디스코드 닉네임 → 화자 라벨.
- **저장**: Supabase 전용 테이블 `meeting_sessions` (DB_OPTIONAL 패턴, 수동 SQL).

## 파이프라인
```
Discord 음성 + Craig → 녹음 (화자별 멀티트랙)
  → [자료 > 회의록 자동작성 > + Craig 가져오기] 녹음 ID/키 입력
  → 백엔드(GPU): Craig 다운로드 → 압축해제 → 트랙별(=화자) ffmpeg→wav
  → faster-whisper 트랙별 STT(타임스탬프) → 시간순 병합 → 대화내역 세그먼트
  → LLM 회의록 요약(안건·논의·결정사항·액션아이템·요약)
  → meeting_sessions 저장 → 세션 목록 + 상세(대화내역 / 회의록)
```

## 데이터 모델 — meeting_sessions
```
id text pk, project_id text, title text, status text(default 'draft'),
source text(default 'craig'), craig_id text, started_at timestamptz,
participants jsonb,          -- [{name, track}]
segments jsonb,              -- [{t, dur, speaker, text}]  (시간순 대화내역)
transcript_text text,        -- 병합 평문(검색/내보내기용)
summary jsonb,               -- {tldr, agenda[], decisions[], action_items[{who,what,due}], topics[]}
duration_sec int, model text, created_by text, created_at, updated_at,
wiki_doc_id text             -- 위키로 내보낸 경우
```

## 백엔드 모듈 (`deepwiki-integration/server/meetings/`)
- `craig_client.py` — `download_recording(id_or_url, key, out_dir)` → 멀티트랙 다운로드/압축해제.
  - Craig 다운로드 API는 버전에 따라 달라질 수 있어 **서버에서 1회 검증·조정** 필요(엔드포인트 상수).
  - 폴백: 직접 다운로드 URL / 업로드 파일도 허용.
- `transcribe.py` — `transcribe_dir(dir, model, lang)`:
  - 각 오디오(트랙=화자) → ffmpeg 16k mono wav → faster-whisper segments(start,end,text)
  - 트랙별 세그먼트에 speaker=트랙 닉네임 부여 → 전체 시간순 병합.
- `summarize.py` — `summarize(segments, title, model)` → 회의록 JSON(LLM, Gemini/Ollama 라우터 재사용).
- `store.py` — Supabase CRUD + `SCHEMA_SQL`.

## API (`/meetings/*`, 미로드 시 503 가드 — refinery 패턴)
- `POST /meetings/import` (SSE) — {craig_id|craig_url, key, project_id, title, model, user_id}
  → 진행 이벤트(stage/track_done/segment/summary/done) 스트리밍 + 세션 저장.
- `GET /meetings/sessions?project_id=` / `GET /meetings/sessions/{id}` / `DELETE …`
- `POST /meetings/{id}/summarize` — 재요약.
- `POST /meetings/{id}/export-wiki` — 회의록을 wiki_docs 로 내보내기.
- `GET /meetings/health` — 모듈/whisper/ffmpeg 가용성.

## 프론트 (`자료` 그룹 → `🎙 회의록 자동작성`, view='meetings')
- 세션 목록(1열): 제목·날짜·참가자·길이·상태.
- [+ Craig 가져오기]: 녹음 ID/키(또는 rec 링크) + 제목 + 모델 선택 → 진행 팝업(SSE).
- 세션 상세 2분할: 좌 = 화자별 색 타임라인 대화내역(타임스탬프 클릭), 우 = 회의록(요약/결정/액션) + [위키로 내보내기].

## 서버 사전 준비(사용자)
- `pip install faster-whisper` + `ffmpeg` 설치(PATH).
- 첫 실행 시 whisper 모델 자동 다운로드(예: `large-v3` 또는 `medium` — GPU 메모리에 맞게).
- Craig 다운로드 엔드포인트 1회 검증(`craig_client.py` 상단 상수).
- `설정 > DB 스키마 점검` SQL 실행으로 `meeting_sessions` 생성.
